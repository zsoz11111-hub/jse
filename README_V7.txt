우리 둘 V7 설치 방법

1. Supabase SQL Editor에서 기존 setup_v5.sql이 아직 실행되지 않았다면 먼저 실행합니다.
2. 이어서 setup_v7.sql 전체를 실행합니다.
3. config.js의 기존 Supabase URL과 Publishable Key는 그대로 사용합니다.
4. 이 폴더의 파일을 GitHub 저장소에 덮어쓰고 커밋합니다.
5. 휴대폰에서 앱이 예전 화면으로 보이면 앱을 완전히 종료 후 다시 열거나 브라우저 캐시를 새로고침합니다.

V7 주요 기능
- 일정 메뉴 추가
- 여행 시작일/종료일을 일정 메뉴에 자동 표시
- 여행 수정/삭제 결과가 일정 화면에도 그대로 반영되는 연결 방식
- 일정 카테고리 추가, 이름 수정, 삭제
- 가계부 카테고리 추가, 이름 수정, 삭제
- 카테고리 삭제 시 기존 항목을 미분류로 이동
- 휴대폰 캘린더용 ICS 파일 생성
- 각 휴대폰별 저장 전/저장 완료 상태를 localStorage로 별도 관리
- 같은 휴대폰에서 재추가 시 중복 경고

주의
- 웹앱은 휴대폰 기본 캘린더에 실제 저장됐는지 직접 확인할 권한이 없습니다.
- '저장 완료'는 이 휴대폰에서 캘린더 추가 버튼을 눌렀다는 기록입니다.
- 앱 삭제 또는 브라우저 데이터 초기화 시 저장 완료 표시는 초기화되지만 휴대폰 캘린더 일정은 유지됩니다.
